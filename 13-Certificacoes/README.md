# 13 — Certificações

[← Voltar para página principal](../README.md)

Certificações organizam objetivos de estudo; o portfólio precisa mostrar execução, raciocínio e limites reais. Nenhuma certificação é declarada como obtida neste projeto.

- [SC-900: segurança, conformidade e identidade](SC-900.md)
- [AZ-900: fundamentos Azure](AZ-900.md)
- [SC-200: operações de segurança](SC-200.md)
- [Security+: fundamentos de segurança](Security-Plus.md)

Escolha conforme sua base: SC-900 e AZ-900 apoiam os fundamentos Microsoft; Security+ amplia fundamentos gerais; SC-200 exige aprofundar operação e investigação. O conteúdo dos labs cobre apenas parte dos objetivos.
