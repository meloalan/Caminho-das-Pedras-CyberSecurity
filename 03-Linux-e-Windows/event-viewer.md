## Conceito

Um evento combina canal, provedor, ID, horário e dados. O mesmo número pode existir em provedores diferentes. XML preserva os nomes dos campos para conferir parsers.

## Prática orientada

Abra o Visualizador de Eventos e filtre Security por 4625 e 4720 após os labs correspondentes. Examine XML, RecordID e horário UTC. Exporte dados brutos apenas para armazenamento privado.
