# Virtualização

[← Índice do módulo](README.md) · [Página principal](../README.md)

## Conceito

Uma VM separa sistemas convidados por meio de um hipervisor. Snapshot facilita retorno a um estado anterior, mas não substitui backup. NAT permite saída; redes internas reduzem exposição entre laboratório e rede doméstica.

## Prática orientada

Crie uma VM com mídia oficial, atualize-a e faça um snapshot identificado. Use rede interna para simulações e NAT temporário para atualizações. Não publique RDP ou SSH na Internet.

## Entrega para o portfólio

Diagrama de rede, versões e procedimento testado de restauração.
