# Git e GitHub

[← Índice do módulo](README.md) · [Página principal](../README.md)

## Conceito

Git versiona alterações localmente; GitHub hospeda repositórios e revisões. Commit registra uma etapa coerente. Remover um segredo do arquivo não o remove do histórico.

## Prática orientada

Clone o repositório, crie uma branch de estudo e altere uma nota. Confira `git diff`, `git status` e os arquivos preparados antes de `git commit`. Use pull request para propor contribuições.

## Entrega para o portfólio

Uma alteração pequena com mensagem clara, sem credenciais, e explicação de branch, commit e remoto.

## Critério de conclusão

Explique o resultado com suas palavras, registre as limitações e diferencie o que foi observado do que foi inferido. Dados de laboratório devem ser anonimizados antes da publicação.
