# HTTP e HTTPS

[← Índice do módulo](README.md) · [Página principal](../README.md)

## Conceito

HTTP define requisições e respostas; HTTPS protege o transporte com TLS. TLS não garante que o conteúdo servido seja benigno. Método, status, host e caminho ajudam a investigar tráfego.

## Prática orientada

Abra as ferramentas de desenvolvimento do navegador em um site público de teste. Examine método, status e certificado sem exportar cookies ou tokens.

## Entrega para o portfólio

Exemplo anonimizado de requisição e explicação dos limites de uma captura cifrada.

## Critério de conclusão

Explique o resultado com suas palavras, registre as limitações e diferencie o que foi observado do que foi inferido. Dados de laboratório devem ser anonimizados antes da publicação.
