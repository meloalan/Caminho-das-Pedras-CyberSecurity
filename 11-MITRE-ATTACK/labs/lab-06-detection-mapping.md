# Lab 06: Mapeamento de detecção

[← Laboratórios](README.md) · [Mapeamento](../detection-mapping.md) · [Strategies](../detection-strategies.md)

## Objetivo

Revisar se uma regra sustenta seu mapping ATT&CK.

## Cenário

Uma detecção de SIEM recebe a tag T1136. Ela alerta quando uma consulta encontra evento de criação de usuário num conjunto de servidores Windows. Não há documentação de teste, ambientes de diretório nem campos do objeto alvo.

## Tarefas

1. Escreva a alegação comportamental mínima sustentada.
2. Identifique quais campos e contexto faltam para escolher subtécnica.
3. Procure Detection Strategy, Analytics e Data Components atuais ligados ao objeto.
4. Descreva testes e fontes complementares necessários.
5. Reescreva a descrição da regra para não alegar cobertura mais ampla.

## Entrega

Complete o template de [ATT&CK Mapping](../TEMPLATE-ATTACK-MAPPING.md) e registre o ID como hipótese se a evidência ainda for insuficiente.
