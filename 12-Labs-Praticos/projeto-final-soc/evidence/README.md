Este diretório não deve conter log real, EVTX, PCAP, dump, arquivo de identidade, token ou segredo.

## Evidência segura para publicar

- Diagrama sem endereços, domínio ou nomes reais.
- Fixture sintética claramente rotulada.
- Captura redigida com usuário, IP, hostname, tenant e identificador sensível removidos.
- Resultado de teste reproduzível sem conteúdo confidencial.
- Hash ou metadado apenas se for apropriado para o exercício e não revelar conteúdo privado.

Mantenha evidência original num armazenamento privado autorizado, com acesso restrito. Observe política de privacidade, retenção e cadeia de custódia da organização. Para o portfólio, documente que dados são sintéticos ou redigidos e como foi feita a sanitização.
