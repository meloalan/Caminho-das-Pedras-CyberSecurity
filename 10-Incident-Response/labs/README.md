# Laboratórios de Incident Response

[← Índice do módulo](../README.md) · [Página principal](../../README.md) · [Dataset sintético](data/README.md)

Os labs progridem de triagem até um caso integrado. Use exclusivamente os dados fictícios fornecidos. Não conecte ferramentas a sistemas reais e não execute ações de produção. As faixas IP são reservadas para documentação ou laboratório; nomes usam `LAB` e domínios `.example.com`.

| Lab | Tema | Entrega principal |
| --- | --- | --- |
| [01](lab-01-triagem-e-classificacao.md) | Triagem e classificação | Fatos, hipóteses, desconhecidos e prioridade justificada |
| [02](lab-02-timeline.md) | Timeline | Cronologia normalizada com event e ingestion time |
| [03](lab-03-scoping.md) | Escopo | Grafo de entidades e limites de busca |
| [04](lab-04-containment-decisions.md) | Decisões de contenção | Comparação de três opções e log de decisão |
| [05](lab-05-identity-compromise.md) | Comprometimento de identidade | Investigação de conta executiva e handoff |
| [06](lab-06-endpoint-incident.md) | Incidente de endpoint | Timeline, escopo, evidência e retorno |
| [07](lab-07-phishing.md) | Phishing | Fluxo mensagem, usuário, identidade, endpoint |
| [08](lab-08-recovery.md) | Recuperação | Plano de backup, validação e monitoramento |
| [09](lab-09-tabletop.md) | Tabletop | Decisões de coordenação e lacunas |
| [10](lab-10-lessons-learned.md) | Lessons learned | Ações com dono, prazo e teste de eficácia |
| [11](lab-11-incidente-completo.md) | Incidente integrado | Pacote de resposta ponta a ponta |

O [dataset JSONL](data/incident-events.jsonl) contém registros simulados para os labs. Consulte seu [dicionário e limitações](data/README.md). Não é telemetria real nem reproduz ferramenta específica.
