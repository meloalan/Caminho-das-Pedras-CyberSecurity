# Playbooks defensivos

[← Índice do módulo](../README.md) · [Página principal](../../README.md)

Use os guias como estrutura de discussão. Adapte critérios, contatos, aprovações, fontes, retenção, obrigações e alternativas ao ambiente. Nenhum passo autoriza por si só alteração real. Sempre valide identidade do alvo, impacto, urgência e autoridade. Os cenários são fictícios.

- [Comprometimento de identidade](identity-compromise.md)
- [Comprometimento de endpoint](endpoint-compromise.md)
- [Phishing](phishing.md)
- [Ransomware](ransomware.md)
- [Identidade cloud](cloud-identity.md)

Este material usa “playbook” como guia de decisão e coordenação. Alguns ambientes usam “runbook” para o procedimento técnico mais específico; a terminologia local pode variar.
